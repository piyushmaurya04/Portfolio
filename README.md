# Piyush Maurya Portfolio

The portfolio is a Vite and React application with TypeScript, Three.js, GSAP, and responsive scene-based sections.

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

The deployed site uses the Netlify configuration in `netlify.toml`. Contact form configuration is kept in the local `.env` file and must not be committed.
